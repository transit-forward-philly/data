# Transit Forward Philly: Data

Open data, analysis, and tools about public transit in the Philadelphia region.

Everything here is free to use. We hope it's useful to researchers, reporters, students, advocates, agency staff, and anyone curious about how transit in our region works.

## What's here

| Folder | What it holds |
|---|---|
| [`datasets/`](datasets/) | Cleaned, documented datasets you can download (CSV, GeoJSON) |
| [`pipelines/`](pipelines/) | Scripts that pull public data from its source so datasets can be refreshed |
| [`analyses/`](analyses/) | Research projects, one folder each, with methods and outputs |
| [`docs/`](docs/) | Templates and guides for contributors |

This repo is just getting started, so some folders are still empty.

## Using the data

- Each dataset has its own README covering what it is, where it came from, when it was pulled, and what each column means.
